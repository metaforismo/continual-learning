# Continual Learning

Research repository for a model-agnostic continual-learning layer for long-running AI agents.

The project starts from a strict boundary: **persistent memory is not automatically continual learning**. The goal is to build and evaluate a system that can preserve evidence, revise beliefs, recall the right experience, learn reusable procedures from verified outcomes, and improve over time without silently corrupting prior knowledge.

The first implementation will be developed through reviewed pull requests. No performance or “infinite context” claim is made yet.
